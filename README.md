### Featured projects

**[SolDiff](https://www.soldiff.in/)** — On-chain program upgrade auditor for Solana
Reconstructs historical Solana program versions from upgrade buffer writes, diffs the binaries, and flags risky changes like removed signer checks. Superteam grant-funded.
`Next.js` `TypeScript` `Solana` `Helius RPC`

**[Athers](https://athers.vercel.app)** — AI voice therapist
Realtime conversational voice with natural barge-in, so you can interrupt and keep talking. Built with Vapi, Deepgram, and Gemini.
`Next.js` `TypeScript` `Vapi` `Deepgram` `Gemini`

**[Just Say It](https://github.com/MisbahAnsar/justsayit)** — AI voice typing for Windows
Global push-to-talk desktop app. Hold Right Ctrl, speak anywhere, and cleaned text pastes into whatever you're typing in.
`Electron` `TypeScript` `Deepgram` `Gemini`

**[solsjin](https://solsjin.com)** — Solana UI kit for React and Next.js
Animated, developer-first components for wallets, balances, transfers, swaps, and NFTs, all running on live RPC data.
`Next.js` `TypeScript` `Solana` `Tailwind CSS`
